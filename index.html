☁️ Konfigurasi Google Cloud Firestore

🔴 Belum Terhubung

Hubungkan ke database cloud Firestore agar tarif harga, data guru, testimoni, dan pendaftar tersinkronisasi otomatis antar perangkat.

1. Buka Firebase Console (console.firebase.google.com) lalu login dengan akun Google Anda.

2. Klik "Tambahkan project" → beri nama misalnya gemabel-group → ikuti sampai selesai.

3. Di pojok kiri atas samping nama project, klik ikon Setelan (Gerigi) → Setelan project.

4. Pada tab Umum (General), Anda akan melihat:

  • ID Project (Project ID) — misal: gemabel-group-a1b2c
  • Kunci API Web (Web API Key) — misal: AIzaSyB3X...

5. Di menu sidebar kiri, buka Build → Firestore Database → klik "Buat database" (pilih lokasi terdekat seperti asia-southeast2 Jakarta) dan pilih Mulai dalam mode uji (Test mode).

6. Salin Project ID dan API Key ke form di bawah ini, lalu klik "Simpan & Hubungkan".

Kembalikan seluruh tarif harga, paket belajar, profil tutor, dan ulasan ke setelan bawaan resmi GEMABEL GROUP.
