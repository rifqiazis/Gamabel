# GEMABEL GROUP – Landing Page & Registration Web App

Landing page modern dan interaktif untuk **GEMABEL GROUP** (Bimbingan Belajar Matematika, IPA, dan Bahasa Inggris).

## Fitur Utama
- 🌟 **Desain Modern & Responsif**: Menggunakan Tailwind CSS dan animasi interaktif.
- 📝 **Formulir Pendaftaran Online**: Integrasi dengan Google Cloud Firebase / Firestore dan opsi WhatsApp otomatis.
- 💳 **Kalkulator Biaya & Paket Bimbel**: Simulasi harga program SD, SMP, SMA.
- ⭐ **Ulasan & Testimoni Interaktif**: Menampilkan rating dan review dari siswa & orang tua.
- 📊 **Panel Admin**: Dashboard pemantau data pendaftar & verifikasi status secara real-time.

## 🚀 Cara Deploy ke Vercel

### Opsi 1: Lewat GitHub (Rekomendasi)
1. Buat repository baru di [GitHub](https://github.com/new).
2. Hubungkan repository lokal ini ke GitHub:
   ```bash
   git remote add origin https://github.com/USERNAME/REPO_NAME.git
   git branch -M main
   git push -u origin main
   ```
3. Buka [Vercel](https://vercel.com/) dan login.
4. Klik **"Add New..."** > **"Project"**.
5. Pilih repository GitHub Anda, lalu klik **"Deploy"**.
6. Website langsung online dalam hitungan detik! 🎉

### Opsi 2: Deploy langsung via Vercel CLI
```bash
npm i -g vercel
vercel
```
Ikuti instruksi di terminal hingga proses deploy selesai.
